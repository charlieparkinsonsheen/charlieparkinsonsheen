# Charlie Parkinson Sheen — Portfolio

A minimal, custom artist-filmmaker portfolio website.

## Files

- `index.html` — homepage
- `project.html` — A Curve in the Sea project page
- `style.css` — all visual styling
- `script.js` — small interactions

## Before publishing

1. Replace the placeholder project images with your own images.
2. Replace the placeholder video on `project.html` with your Vimeo embed.
3. Change the email address and social links in `index.html`.
4. Add more project pages as needed.

## GitHub Pages

Create a new GitHub repository, upload all files, then go to:

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save

GitHub will give you a public website address. You can later connect your own domain.
